# K12 Hunar Scholarship CRM Demo

A frontend-only Scholarship Management CRM demo for the K12 Hunar Frontend Developer Assessment.

## Features

- Dashboard counts for total, published, draft, and expired scholarships
- State filtering and scholarship-name search
- In-place status changes with live dashboard updates
- Add and edit scholarship form with required-field and application-link validation
- Student-facing scholarship preview
- Responsive layout for desktop and mobile screens

## Run locally

```bash
npm install
npm dev
```

Open the local URL printed by Vite. To create a production build, run `pnpm build`.

## Implementation notes

The app uses React client state and local sample data. No backend, authentication, or external API is required for this assessment.
